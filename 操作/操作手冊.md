## 一、系統架構

```
LabVIEW（任何電腦）
    ↓ HTTPS POST
Railway 雲端 Flask（24小時常駐）
    ↓
瀏覽器打開 web-production-0ed68.up.railway.app
```

- Flask 跑在雲端，**不需要手動開啟任何程式**
- 任何能上網的裝置都能打開監控網頁
- LabVIEW 只要能上網，資料就會自動傳到雲端

## 四、Railway 操作

### 正常監控
直接在瀏覽器打開：
```
https://web-production-0ed68.up.railway.app
```

### 網頁打不開時
1. 前往 https://railway.app 登入
2. 點專案 → 點 **web** 服務
3. 點 **Deployments** → 最新那筆右邊 `⋮` → **Redeploy**
4. 等 1-2 分鐘後重新整理網頁

### 更新程式碼後自動重新部署
把新的檔案上傳到 GitHub 後，Railway 會**自動偵測並重新部署**，不需要手動操作，約等 1-2 分鐘生效。

### 注意事項
- Railway 免費方案每月 $5 額度，用量低不太會超
- 重啟後記憶體資料清空，但即時監控不受影響
- 如遇異常可去 Railway → **Deploy Logs** 查看錯誤訊息

## 五、常見問題

### git push 被拒絕（rejected / fetch first）
代表 GitHub 上有這台沒有的東西，先拉再推：
```bash
git pull
git push
```

### 跳出全螢幕文字編輯器（vim）
```
按 Esc → 輸入 :wq → 按 Enter
```

### 出現 (main|MERGING) 無法操作
```bash
git merge --abort
git pull
git push
```

### GitHub 上版本跟本機衝突，直接用 GitHub 版本覆蓋本機
```bash
git fetch origin
git reset --hard origin/main
```

### 確認目前這個資料夾追蹤的是哪個 repo
```bash
git remote -v
```

## 七、一句話記憶

```
更新監控系統  → cd Flask        → git pull
更新備份程式  → cd python-labview-project → git pull
做完備份      → git add . → git commit -m "說明" → git push
網頁掛了      → Railway 面板 Redeploy
```
如果你不要本機所有修改，直接用 GitHub 最新版本覆蓋，可以使用下面的指令。

⚠️ 這會永久刪除你本機尚未提交的修改，無法復原。

git reset --hard HEAD
git clean -fd
git pull

如果想更徹底，直接讓本機與 GitHub 完全一致，可以使用：

git fetch origin
git reset --hard origin/main
git clean -fd

這組指令的作用是：

git fetch origin：下載 GitHub 最新內容。
git reset --hard origin/main：將本機 main 分支直接重設成與 GitHub 的 main 完全相同。
git clean -fd：刪除所有未追蹤的檔案與資料夾。

最後可以確認是否同步成功：

git status

應該會顯示：

On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean

如果你的目的就是「GitHub 有什麼，我的電腦就變成什麼」，我建議直接使用第二組 (fetch + reset --hard + clean)，這是最乾淨、最不容易出問題的方法。
